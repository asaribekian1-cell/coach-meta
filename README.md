# coach-meta

Мета для приложений CS2 Coach и Dota Coach. Здесь только цифры: эталоны про-игроков и раскидки, никакого кода.

- `cs2/meta.json` — мета CS2. Приложение раз в неделю скачивает её отсюда и пересчитывает отчёты.
  Чтобы выпустить новую мету, пересоберите её (`python tools/build_meta.py <папка с про-демками>`),
  поднимите `version` и положите файл сюда.
- Dota Coach собирает мету сам из OpenDota каждый день, файл здесь не нужен.
